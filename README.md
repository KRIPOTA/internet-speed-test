# Internet Speed Test

Небольшой консольный скрипт на Node.js для измерения скорости скачивания файла.

## Требования

Node.js 18 или новее. Дополнительные зависимости не нужны.

## Запуск

```bash
node index.js "https://example.com/large-image.jpg"
```

Замените ссылку на адрес доступного файла, например большой картинки. Желательно использовать достаточно большой файл, чтобы результат был показательнее.

## Как работает

1. Последовательно выполняет 10 GET-запросов к указанному URL.
2. Каждый раз дожидается полной загрузки ответа.
3. Вычисляет среднее время запроса и суммарный объём скачанных данных.
4. Выводит среднюю скорость скачивания в Мбит/с.

## Единицы измерения

- **с** — секунды, включая время получения ответа и загрузки данных.
- **байт** — суммарный объём тела всех 10 ответов.
- **Мбит/с** — мегабиты в секунду (1 Мбит = 1 000 000 бит, 1 байт = 8 бит).

Скорость вычисляется как `(суммарный объём в байтах × 8) / (суммарное время в секундах × 1 000 000)`. Это средняя скорость загрузки данных за время 10 запросов, включая задержку ответа сервера.
